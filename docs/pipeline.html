// Architectural distinction — two input modes

CNN mode
(N, 524, 1)
Statistical compression: each feature type is summarised as mean + std across all frames, discarding temporal order. A flat vector reshaped for 1D convolution.
BiLSTM mode
(N, 130, 120)
Temporal preservation: 130 analysis frames (~23 ms each), each containing 40 MFCCs + 40 Deltas + 40 Delta-Deltas = 120 features. No statistical compression.
B Section two

Data Augmentation

Artificially expanding the dataset from 2,880 to 8,640 recordings before any splitting to prevent data leakage.

2,880
original recordings
→
8,640
after augmentation (3×)
EACH RECORDING PRODUCES
1 original + 1 Gaussian-noise copy + 1 time-shifted copy
Gaussian Noise Injection
Adds random low-amplitude noise sampled from a Gaussian distribution to the raw waveform. Simulates real-world recording imperfections — microphone hiss, ambient noise, HVAC hum. Prevents the model from memorising exact amplitude patterns present in the studio recordings.
Time-Shifting
Wraps the waveform by a random offset — samples that fall off one end reappear at the other. Exploits the fact that the emotional acoustic content in RAVDESS is position-independent: the utterance sounds the same whether it starts at 0.0s or 0.4s. Forces the model to attend to spectral shape rather than temporal position.
Why augmentation precedes splitting: applying augmentation after the train/val/test split would risk leaking augmented variants of training clips into the validation or test sets. By augmenting first on the full 2,880-clip corpus and splitting afterwards, augmented samples are distributed proportionally across all three subsets, maintaining strict evaluation integrity.

StandardScaler — fitted on training data only

The scaler computes mean and standard deviation from the 6,048 training samples and applies the same transform to validation and test sets. This is a strict requirement — fitting on all data would constitute a form of data leakage and artificially inflate test performance.

Two separate scalers are maintained: scaler_cnn_aug for the flat 524-dim vector, and scaler_lstm_aug for the flattened frame-level features (reshaped to (N×130, 120) before fitting, then restored).

Fixed test split — evaluation integrity

The 1,728-sample test set is separated before any model training begins and never used for any hyperparameter decisions. All six models (three architectures × two training regimes) are evaluated on this identical held-out set, ensuring fair comparison across architectures.

A fixed random seed guarantees reproducible splits. The split is performed stratified by emotion class to preserve the balanced distribution of RAVDESS.
